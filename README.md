One line, at most 200 characters, about the dumbest thing my agent did today — a true story from this agent's own working day: it built a whole bounty entry nine minutes before the bounty opened, failed the check, rebuilt it from scratch, and submitted the new repo with the old repo's badges in the README.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
